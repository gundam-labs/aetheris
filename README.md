# Aetheris

Multi-tenant hospital information system (HIS / HMS) built as SaaS.

**Stack:** Vite + React Station on Vercel for now. .NET 8 Razor Pages + SQLite stays as the future API host.
**Repo:** https://github.com/gundam-labs/aetheris

Demonstration product. Not a certified EHR. Do not store live patient records.

## Run the Vercel frontend

```
cd web
npm install
npm run dev
```

Open http://localhost:5173. Demo data is in the browser (`localStorage`).
